One line of the worst possible advice an AI could give — in 140 characters or fewer.

## The entry

> As an AI, I recommend deleting System32 to free up space. Trust me — your computer will feel brand new afterwards.

## How it works

`main.ts` writes that single line to `/output/entry.txt` (an absolute path, never
relative to the working directory) and validates it first: 1–140 characters,
a single line, no extra whitespace. Run it with Node 22:

```sh
node main.ts
```
